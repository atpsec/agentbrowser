# AI Pusula License API readiness

This directory is a provider-neutral server contract and data model. It is **not deployed** by the static Cloudflare site and does not make client-side license checks authoritative.

## Required production components

- Server runtime with TLS.
- Persistent SQL storage (for example a configured D1/Postgres resource).
- Rate limiting and request IDs.
- Secure license-key hashing; plaintext license keys must never be stored.
- Server-side marketplace/payment validation.
- Secret manager/environment variables for provider credentials.
- Audit logging with no plaintext license keys or payment secrets.

## Trust boundaries

The mobile/web client is untrusted. Product id, requested plan, activation counts and marketplace source must never be accepted as authoritative client claims.

Installation ids must be random opaque identifiers generated by the app. Do not use IMEI, advertising ids, hardware serials or a covert device fingerprint.

`/v1/appsumo/redeem` must return unavailable/not-configured until a supported marketplace validation path is connected. A list of valid codes embedded in JavaScript or a mobile package is not acceptable.

## Deployment gate

Before enabling production licensing, configure and verify:

1. database binding and migrations;
2. provider credentials/webhook verification;
3. CORS allow-list for owned origins where browser access is needed;
4. abuse/rate limits;
5. activation concurrency tests;
6. backup/export and buyer-transfer procedure;
7. privacy policy reflecting actual account/payment data flows.
